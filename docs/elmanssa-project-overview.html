Elmanssa Education Platform

Comprehensive technology and project overview for the frontend and backend repositories.

Elmanssa is an Arabic-first, RTL online learning platform designed for the Arabic-speaking market, with a strong focus on students, teachers, and administrators. The project includes a rich frontend experience with a .NET backend API, secure media handling, role-based access, AI tutoring, and payment flows.

1. Product vision and business scope

The platform is not a simple course catalog. It is an end-to-end learning ecosystem. Students can browse courses, enroll, complete lessons, track progress, and access AI tutoring. Teachers can publish content, manage curriculum, review students, and monitor earnings. Administrators can oversee courses, users, payments, accounting, media, and platform-wide operations.

The product targets students in Egypt and Saudi Arabia, with Arabic-first UX and language-specific content flows. This includes RTL layout, Arabic marketplace behavior, support for Arabic education paths, and a strong focus on local usage patterns and market requirements.

3. Frontend architecture and product experience

The frontend is built as a single-page application with a lightweight custom routing layer instead of a traditional router library. This keeps navigation fast and allows deep linking to course pages, dashboard views, admin modules, and content-specific routes.

  • Role-based dashboards for students, teachers, and admins.
  • Course marketplace with search, filters, listing pages, ratings, and rich detail pages.
  • Secure media learning experience with HLS streaming and video player controls.
  • AI study assistant UI with conversation history and markdown rendering.
  • Checkout flow and payment handling through backend service integration.
  • Marketing pages for home, about, pricing, support, privacy, blog, and instructor profiles.

The application also includes route-level code splitting, cache strategies, input sanitization, XSS mitigation, and open-graph preview generation for course sharing.

This is not a generic demo app. It is built to feel like a real educational platform with market-facing pages, business workflows, and authenticated modules.

4. Backend architecture and API design

The backend is a layered ASP.NET Core service designed around clear separation of concerns. Controllers handle HTTP requests, services contain the business logic, repositories manage data access, and the data layer coordinates EF Core models and SQL Server persistence.

  • Authentication and authorization through ASP.NET Core Identity.
  • JWT access tokens and refresh tokens for session management.
  • Course CRUD with publish, draft, search, and category filtering.
  • Enrollment tracking with lesson progress, completion states, and drop flow.
  • AI usage tracking, quotas, and token-based cost awareness.
  • Swagger UI available for interactive API testing in development.

The backend also includes supporting patterns such as generic repository abstractions, unit-of-work coordination, DTOs for API contracts, configuration classes for email, AI, and rate limits, and structured environment-based setup.

6. Security and reliability

Security is treated as a core product requirement. The platform includes JWT authentication, route-level access checks, refresh-token rotation, email verification, and structured request validation. The backend uses quotas, request throttling, and rate limiting to guard against misuse and excessive AI consumption.

The frontend also uses sanitization and protection patterns for user-provided content and dynamic output, and it is designed for secure deployment in a real production environment with Vercel hosting and backend API integration.

7. Media, payments, and AI

  • Video learning includes protected streaming flows and signed asset access.
  • Media upload pipeline is prepared for compression and transcoding workflows.
  • Payments flow through Paymob-based checkout actions and order handling.
  • AI study assistant is connected to Gemini and scoped to educational support.
  • Usage quotas ensure fair and measurable AI consumption per user.

8. Deployment and environment

The frontend is deployed through Vercel, while the API is hosted on a .NET backend environment. Local development commonly runs the frontend at localhost:3000 and the API at a backend port such as localhost:5299 or similar, with Vite dev-server proxying requests to the API. Production deployment uses environment configuration for the API base URL and public-facing origin variables. The platform is designed to support a real SaaS-style lifecycle.

9. Summary

The Elmanssa ecosystem is a mature educational platform combining a modern React frontend, a scalable ASP.NET Core backend, secure authentication, rich media and video support, AI tutoring, payments, role-based dashboards, and a strong Arabic-first UX. It is designed not only as a course website but as a full learning operation system for students, teachers, and administrators.
